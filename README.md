Telegram Karaoke Bot

بوت تيليجرام لفصل صوت المغني عن الموسيقى باستخدام Demucs.

الملفات

- bot.py: الكود الرئيسي للبوت.
- requirements.txt: مكتبات Python.
- Dockerfile: إعداد بيئة التشغيل.
- render.yaml: إعدادات نشر الخدمة.

التشغيل

1. أنشئ بوتًا باستخدام BotFather.
2. أضف متغير البيئة BOT_TOKEN في إعدادات الاستضافة.
3. انشر المشروع باستخدام Docker.
4. أرسل "/start" إلى البوت.

ملاحظات

تحتاج معالجة الأغاني إلى ذاكرة ومعالج مناسبين. قد تفشل معالجة الملفات الطويلة على الاستضافات محدودة الموارد.
